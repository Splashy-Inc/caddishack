# CaddiShack

“A cozy, bug bead-based bracelet builder”

CaddiShack is a 2D engine-builder game where the player has to meet progressively scaling quotas by releasing caddisfly larvae in terrariums to create beads that score points in constructed jewelry. The engine is the player’s “deck” of caddisfly larvae that acquire attributes over time via store purchases at the beginning of each round.
